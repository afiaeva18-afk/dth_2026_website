# The Disadvantages of Open Source Software

There are a number of disadvantages of open source software that are unrelated to costs. These include reliability and security.

For one, many open source projects don’t have dedicated support personnel. Often times the best way to get help is to contact support online. In many cases, customers are left to resolve support cases on their own.

An additional concern is project abandonment. There are many open source projects that start and then are discontinued. Especially if the project does not gain a lot of initial traction and support, project development and maintenance can quickly lose priority for participants.

Security is another major issue. Of course, public code provides opportunities for programmers to assess and overcome weaknesses. However, public code provides opportunities for bad actors to do the same. In addition, if there are just a few programmers involved in a project, security issues may be completely ignored. This is especially dangerous for projects involving sensitive and/or secure information.

Also, the user is still required to do a great deal of programming to set up and integrate some pieces of open-source software with other hardware and/or software. In addition, particular pieces of open-source software may not interface well with peripheral hardware and software.

Also, while there is no cost to download and use software, hardware, and firmware, this does not mean that there is no cost to develop and maintain these.

Thus, given the unpredictability of open-source software maintenance, support, and development, users of such software must first determine the reliability of particular software to meet their needs.
